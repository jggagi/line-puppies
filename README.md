## 🌟 核心特色与功能 (Highlights)

- **🖼️ 100% 纯手绘原版漫画美术**：
  - 完全移除了 AI 生成，采用 100% 原版线条小狗的温暖漫画作为场景，完美契合 `moonlab_studio` 的软萌治愈风格。
  - 主舞台采用极简拍立得（Polaroid）卡片边框设计，背景随时间段变化。
- **⏱️ 双重时间流逝周期**：
  - **快速模拟模式 (Fast-Sim)**：自动在四个温馨生活片段（日常、戏水、观星、生病）之间切换。
  - **系统实时模式 (Real-time)**：随你所在时区的本地时间进行真实场景切换：
    - 🌅 *上午 (07:00 - 12:00)*：日常贴贴 (🏡 Cozy Home)
    - ☀️ *下午 (12:00 - 17:00)*：夏日戏水 (🏖️ Swimming)
    - 🌌 *傍晚 (17:00 - 22:00)*：星空许愿 (🌠 Stargazing)
    - 🛌 *深夜 (22:00 - 07:00)*：照顾感冒 (🤒 Sick & Nursing)
- **💬 浪漫双向心心对话 (Sweet Talk & Intimacy)**：
  - 小黄与小白头上会动态冒出专属的心形对话框，在不同场景下会说出不同的温馨、搞怪悄悄话。
  - 你可以随时喂它们“送爱心 💖”或让他们“说悄悄话 💬”来积攒亲密度。
  - **恋爱等级**不断升级，解锁如“灵魂伴侣 (Soulmates)”等浪漫称号！
- **💾 LocalStorage 本地存档机制**：
  - 拥有完善的本地存档系统，自动保存小狗的名字、恋爱等级、当前进度以及**整本恋爱日记的所有历史日志**。
  - 刷新网页、关闭浏览器甚至几天后再打开，数据依然完美无缝恢复！
- **⚡ 超轻量零依赖 (Self-Contained)**：
  - 整部应用深度压缩优化，仅有单一 HTML 文件（**292KB**），所有图片资产以 Base64 高清嵌入，不需要任何服务器和网络请求，直接双击或点击就能加载。

## 📸 恋爱日记场景剪影 (Interactive Scenes)

1. **日常贴贴 🏡 (Cozy Home)**：小白和小黄并排在软绵绵的地毯上，摇着快乐的小尾巴。
2. **夏日戏水 🏖️ (Swimming)**：套上黄色游泳圈，漂浮在清凉的海面上，惬意地喝着冰镇可乐。
3. **星空许愿 🌌 (Stargazing)**：并排躺在午夜的草地上，在滑过的颗颗流星前许下心愿。
4. **生病照顾 🤒 (Sick & Nursing)**：小白夜里着凉发烧，小黄端来热腾腾的水和毛毯，心疼并贴身陪伴照顾。

## 🚀 线上预览与部署 (Deployment)

应用已成功提交并自动部署！

### 🔗 官方在线预览地址：
👉 **[https://jggagi.github.io/line-puppies/](https://jggagi.github.io/line-puppies/)**

### 🛠️ 自行部署非常简单：
由于该应用为纯单页静态 HTML（自包含图片），只需要在你的 GitHub 仓库中：
1. 前往 **Settings -> Pages**。
2. 在 **Build and deployment** 部分选择 **Deploy from a branch**。
3. 设置分支为 **`main`**，目录为 **`/ (root)`**。
4. 点击 **Save**，一分钟后即可通过你的 GitHub Pages 域名进行访问！
